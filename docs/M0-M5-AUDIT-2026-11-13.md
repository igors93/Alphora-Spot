## Verificações executadas

- Suíte Python completa: **4.602 passaram, 2 pulados**, em Python 3.10.11. O aviso único vem do teste que simula uma falha em thread (`test_threading_hook_writes_crash`).
- Golden replay: **20 execuções consecutivas passaram** em Python 3.10.11, com os 14 cenários em cada execução.
- `ruff check src/ tests/`: passou. `ruff format --check src/ tests/`: **975 arquivos formatados**.
- `python -m mypy src`: passou em **498 arquivos**.
- Catraca e camadas: **4 testes passaram**. Medidas: 0 ciclos, 0 campos `Any`, 0 mixins, 0 exclusões mypy, 0 referências legadas fora dos nomes persistidos. Há 45 funções acima de 150 linhas e a maior tem 684 linhas (`load_config`); as metas globais correspondentes pertencem às fases seguintes.
- Testes dirigidos da integração REST: **30 passaram**. Testes dos caminhos corrigidos de configuração, estado e prefetch: **26 passaram**.
- `cargo fmt --check`: passou. `cargo clippy` e `cargo test` foram tentados, mas a compilação das dependências da interface esgotou o espaço local em disco. `cargo clean` removeu 1,1 GiB de artefatos; não houve conclusão desses dois gates Rust nesta máquina.

## Pendências fora dos critérios de saída M0–M5

- **M5, OPT-010 e OPT-011:** otimização de REST/cache e controle de memória requerem medições comparáveis em TESTNET/REAL. A decisão de tornar `ALPHORA_REST_WEIGHT_GUARD_MODE=ENFORCE` o padrão depende das mesmas medições; o padrão continua `OBSERVE`.
- **M6/M7:** as 4 exceções de camadas remanescentes, G9, parte da unificação dos gates e a redução das funções grandes continuam nos destinos indicados no plano. Esses itens não são apresentados como concluídos nesta auditoria.
- A matriz de Python 3.11–3.13 está configurada no CI, mas não foi executada localmente. Esta auditoria não realizou negociação real nem medição de produção.
